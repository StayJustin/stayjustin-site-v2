# Email Research

Use this folder for city emails, public records responses, correspondence, clarifications, and follow-up answers.

## What to Track

- Sender and recipient
- Date sent
- Topic
- Public records request number, if any
- What was answered
- What was not answered
- Whether attachments were included
- Whether information should be public, limited, or private

## Handling Rule

Emails are useful evidence, but handle them carefully. Do not publish private personal contact information unless it is already part of the public record and clearly relevant.

## Common Tags

Emails, Public Records, Staff Response, Follow-Up, Evidence, Clarification
