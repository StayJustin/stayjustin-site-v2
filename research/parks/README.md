# Parks Research

Use this folder for park projects, recreation programs, playgrounds, sports fields, Measure A spending, youth programs, and park-related development impacts.

## What to Track

- Park project budgets
- Measure A reimbursements
- Playground and field improvements
- Youth sports programming
- Program cancellations or pauses
- Contractor costs and deadlines
- Public feedback
- Park land dedication from development projects

## Open Questions

- Were park projects completed on schedule?
- Were funds reimbursed as expected?
- Which programs were paused, reduced, or expanded?
- How are park improvements distributed across the city?
