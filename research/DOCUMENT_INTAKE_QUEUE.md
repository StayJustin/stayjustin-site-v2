Use this file to track documents that need to be processed into the research library.

## Intake Status

| Status | Meaning |
| --- | --- |
| New | Document has been received but not reviewed. |
| Processing | Summary, facts, money, and questions are being extracted. |
| Needs Follow-Up | Important gaps remain. |
| Filed | Research summary and related notes are stored in the correct issue folder. |
| Published | Document has supported an article, issue hub, post, Substack, or video. |

## Priority Guide

High priority:

- Active council agenda item
- Large dollar amount
- Direct resident impact
- Confusing public process
- Safety issue
- Deadline approaching

Medium priority:

- Useful background
- Older document connected to current issue
- Contract or staff report that explains context

Low priority:

- Archive-only document
- No immediate story or issue connection yet
